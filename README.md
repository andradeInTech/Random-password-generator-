🔐 Random Password Generator

A simple and interactive random password generator built with HTML, CSS, and JavaScript.

This project was developed as part of the Scrimba Full Stack Developer Path, focusing on JavaScript fundamentals, DOM manipulation, and interactive web development.

🚀 Features

- Generate two random passwords with a single click.
- Each password contains 15 randomly selected characters.
- Passwords include uppercase letters, lowercase letters, numbers, and special characters.
- Generate new passwords without refreshing the page.
- Clean and user-friendly interface.

🛠️ Technologies Used

- HTML5 — Page structure.
- CSS3 — Styling and layout.
- JavaScript — Password generation and DOM manipulation.
- Vite — Development tooling included in the Scrimba starter project.

📚 What I Learned

During this project, I practiced:

- Creating and calling JavaScript functions.
- Using "Math.random()" and "Math.floor()" to generate random indexes.
- Working with arrays and "for" loops.
- Using "return" to retrieve values from functions.
- Updating HTML elements with ".textContent".
- Handling button clicks with "addEventListener()".
- Generating dynamic content without reloading the page.
